PP

A small language/runtime experiment for reproducible, capability-scoped computation

pp is a content-addressed, capability-scoped language with a tree-walking evaluator. Values carry content hashes, so identical code and inputs can naturally share cached work. Side effects need explicit capabilities, which keeps programs honest about what they’re allowed to touch.

It’s written in OCaml and comes with incremental builds, artifact storage, supervision, parallel scheduling, and a path toward distributed execution. It’s still evolving, but the goal is pretty simple: a small, principled foundation for running real work.
